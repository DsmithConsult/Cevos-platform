# CEVOS Roadmap

## Community EV Operating System

**Affordable • Modular • Open Source**

This roadmap outlines the planned evolution of CEVOS from a vehicle conversion planning tool into a comprehensive platform for EV design, simulation, collaboration, and deployment.

---

# Project Status

**Current Phase:** Core Platform

**Current Version:** v0.3.0

**Primary Prototype Vehicle:** Infiniti QX60 (2017)

---

# Project Vision

CEVOS aims to become the leading open-source platform for:

- EV conversion planning
- Vehicle electrification simulation
- Engineering collaboration
- Component selection
- Community knowledge sharing
- AI-assisted conversion design

---

# Development Principles

Every feature must support at least one of the following goals:

✅ Improve engineering accuracy

✅ Reduce conversion complexity

✅ Increase affordability

✅ Improve accessibility for builders and educators

✅ Encourage open collaboration and transparency

---

# Roadmap Phases

## Phase 1: Foundation

Focus on establishing the platform structure, community infrastructure, and core data model.

### Planned Work
- Establish the repository structure and documentation
- Define the vehicle library format and data model
- Create the initial project README and contribution workflow
- Document the prototype vehicle and early component concepts

---

## Phase 2: Core Platform

Expand the platform into a usable planning environment.

### Planned Work
- Build the frontend experience for browsing vehicles and components
- Implement backend services for project data and configuration
- Add initial simulation and estimation tools
- Support simple project and conversion configuration workflows

---

## Phase 3: Advanced Engineering Tools

Introduce more sophisticated engineering and analysis capabilities.

### Planned Work
- Expand the AI engineering advisor capabilities
- Improve 3D visualization and packaging tools
- Support richer reporting and export workflows
- Introduce deeper performance and weight distribution calculations

---

## Phase 4: Community and Ecosystem Growth

Grow the platform into a collaborative open-source ecosystem.

### Planned Work
- Add more vehicle and component datasets
- Encourage community contributions and validation
- Improve documentation, onboarding, and collaboration workflows
- Support shared project templates and community best practices

---

# Milestones

## v0.1
- Initial repository setup
- Prototype vehicle documentation
- Foundation for vehicle and component libraries

## v0.2
- Early web-based planning experience
- Basic simulation calculators and configuration tools

## v0.3
- Input-based static weight-balance planning with explicit measurement and safety limitations
- User-entered added/removed conversion component weights and locations in weight-balance estimates
- Sourced component mass metadata for weight-balance estimates
- Reports that disclose estimates, assumptions, weight-balance inputs/results, and screening limitations
- Actionable engineering-advisor screening with visible rule basis and next steps
- Expanded engineering analysis
- Improved AI-supported design guidance

## v1.0
- Mature open-source platform for EV conversion planning and collaboration
